# רתם — הזמנה קולנועית

**מצב שיתוף:** Public GitHub Pages (כל מי שיש לו את הקישור יכול לצפות בטקסט ובנכסים).

## שדרוג מהיר
- `content.js` — שם, הודעות סוד, שעה, הגדרות מוזיקה ונוסחי הסיום.
- `index.html` — מבנה הפרקים ומטא־נתונים לשיתוף.
- `style.css` — העיצוב והאנימציות.
- `assets/` — מדיה שאושרה לפרסום.

## איכות
האתר מותאם למובייל, כולל reduced-motion, שמירת Easter Eggs ב־localStorage, ושמע שמתחיל רק אחרי מגע יזום.
